レスポンス例サンプル

実際に支払い（x402 / USDC on Base・$0.30）を済ませたあと、POST /x402/analyze が返すレスポンスが、おおよそこういう形です。

ここでは「食用油（cooking_oil）」を例にしています。非・数値の見え方など、購入前にイメージをつかんでください。

リクエスト
POST /x402/analyze { "target_name": "cooking_oil", "sector": "food_basic" }
200 OK 支払い後のフルデータ
{ "oracle_timestamp_utc": "2026-08-19T05:44:00+00:00", "item_name": "cooking_oil", "sector": "food_basic", "data_type": "cpi", "raw_value": 13.8, "base_yoy": 1.0, "delta": 12.8, "usdjpy_yoy": 12.01, "fx_adjusted_delta": 0.79, "alert_level": "EXTREME", "is_anomaly": true, "report_jp": "【cooking_oil】前年同月比=+13.8%（CPI総合比+12.80%ポイント）。円安調整済み=+0.79%ポイント。アラートレベル: EXTREME。" }
※ 数値は実データに基づく例示です。実際の値はリクエスト時点の最新配信に依存します。
KYA（無料・身元確認のみ） 支払い前なら、ここまでだけ見える
{ "item_name": "cooking_oil", "alert_level": "EXTREME", "report_jp": "【cooking_oil】アラートレベル: EXTREME。詳細な数値データは有料プレビューです。" } // alert_level のみ。delta・base_yoy などの数値は返らない
アカウント・APIキー・本人確認は不要です。x402（USDC on Base）で$0.30/リクエストを払うと、フルデータが返ります。 払わなければ（KYAのみ）、アラートレベルだけが返る無料プレビューです。
